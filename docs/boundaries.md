# Version 0.1.0 boundaries

An in-memory property graph bounded to 65,536 nodes and 262,144 edges; node and edge IDs are 1..256 characters. Shortest paths use binary-heap Dijkstra at O((V+E) log V) with (distance, id) tie-breaking and reject negative weights. Components are sorted for reproducible output. Impact analysis follows incoming edges up to the requested depth (default 1). Critical paths are longest weighted chains on acyclic graphs only; cycles are refused rather than walked. No graph query language or disk database. Numeric weights use finite Double. Snapshots are JSON graph data validated again on import.
